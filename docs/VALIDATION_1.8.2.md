本地检查记录 — V1.8.2（2026-11-21）

已确认的代码缺陷：
V1.8.1 用 Range.Width / Height 直接计算最终页面，只核对页面框尺寸，未核对实际打印区域边界。复现样例中，实际区域宽 620 pt，预估宽 562.39 pt，旧方法会裁掉右边框和金额末尾。

本次修改：
1. 导出原 PDF 后，在同一工作簿内创建临时工作表副本，设置四种不同颜色的外边框并额外导出，用以测量实际打印区域。保留区域内部空行、空列。
2. 按实测边界加四边留白调整页面，不改变文字、图片及表格的缩放比例。临时副本和测量 PDF 删除，源工作簿不保存。
3. 检查四条边界闭合、原 PDF 与测量 PDF 的纸张/旋转/单位一致。实际分成多页、区域超出纸张时尝试更大纸型；测量失败则停止，不覆盖已有 PDF。
4. 最终页面扩大到旧纸张之外时，保留旧纸张裁切范围，避免原来不可见的内容被意外显示。
