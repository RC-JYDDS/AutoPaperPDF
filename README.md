# AutoPaperPDF

通用表格 PDF 自动选纸工具。通过本机 Excel 或 WPS 将指定工作表区域导出为 PDF，最终 PDF 页面按“打印区域尺寸＋四边留白”生成，保持 100% 原尺寸。

当前源码版本 **V1.8.5（2026-11-21）**。维护者：**AnAn（[@RC-JYDDS](https://github.com/RC-JYDDS)）**。

## 功能

- 选择工作簿、工作表和连续打印区域；留空时使用表格已有打印区域。
- 优先选择可容纳内容的常见 A4/A3 等中间纸型；用同一工作簿内的临时工作表副本测量实际打印边界，再生成指定留白的 PDF。
- 只调整 PDF 页面边界，不缩放或重绘文字、图片和表格。
- 使用表格原页边距，或分别设置上、下、左、右页边距（0–100 毫米），并显示当前数值。
- 设置并记住文件名称、前缀和后缀；`{日期}` 替换为不带分隔符的 `yyyyMMdd`。
- 可选细边框优化，将识别出的 WPS 约 1 磅实心表格线调整为 0.5 磅。
- 单个 Windows 图形程序，无控制台窗口；所需开源 DLL 嵌入 EXE。

## 运行要求

- Windows 桌面环境、.NET Framework 4.7.2 或兼容的更新版本。
- 已安装并可通过 COM 调用的桌面版 Microsoft Excel 或 WPS 表格。
- 表格软件具有可用的纸型配置。工具查询相关配置来排版，不发送纸质打印任务。

本项目不包含 Excel、WPS 或其许可证。不同软件版本、字体和纸型配置会影响导出效果。

## 使用方法

1. 在 Excel/WPS 中填写表格，设置打印区域并保存文件。工具读取磁盘中已保存的内容。
2. 打开工具，选择表格软件和文件，再选择工作表。需要时输入连续区域，例如 `A1:N20`。
3. 点击页边距按钮，选择原设置或填写四边数值。
4. 填写文件名称；需要日期时，在前缀或后缀中加入 `{日期}`。
5. 点击“按原尺寸导出 PDF”，选择保存位置，再核对 PDF 的分页、金额和签名图片。
6. 在“导出完成”窗口点击“打开文件所在位置”，资源管理器会选中刚保存的 PDF。

工具以只读方式打开工作簿，导出时不保存对源表格的排版更改。如果软件把请求转交给已有工作簿窗口，工具会停止并提示先保存、关闭该软件中的工作簿，或切换另一软件。

### 边界与限制

页边距从选定打印区域的外边界计算。区域内部的空行、空列以及文字所在单元格的内部空白会保留，不会按墨迹自动裁切。例如打印区域为 198.4 × 103.0 毫米，四边各设 5 毫米，最终 PDF 为 208.4 × 113.0 毫米。

导出时会关闭页面居中，再依据 PDF 中实际打印的单元格边界设置四边留白。为避免接口尺寸与实际打印尺寸不同造成裁切，工具会在同一工作簿内创建一个临时工作表副本，仅在副本上设置四种颜色的测量边框并额外导出一次。测量副本及测量 PDF 随后删除；交付 PDF 不含测量标记，源工作簿不保存这些临时改动。若工作簿结构保护、工作表保护或软件接口不允许测量，工具会停止，保留已有 PDF。

中间排版仍需要本机提供能以 100% 大小容纳内容的纸型；没有合适纸型或实际导出多页时会停止，不缩小内容。重复打印的标题行、标题列完全位于所选打印区域内时，可以正常导出，不需要修改表格。若标题范围超出所选区域，或存在页眉页脚、打印行列标号，工具会指出具体设置，不会直接裁掉这些额外内容。字体和图片的实际渲染由 Excel/WPS 决定。

打印到实体纸张时，请选择“实际大小/100%”。若所用纸张比 PDF 页面大，实体纸张仍会剩余空白。

细边框优化针对特定线条表示形式，不适用于所有 PDF。遇到异常可关闭此选项，保留原线条；页面尺寸调整仍然生效。

### V1.8.4 受保护工作表与四边测量

程序先检查临时工作表的保护状态。对受保护的副本显式使用空密码，并确认保护已经解除后才写入标记。需要保护密码时会停止导出，保留已有 PDF。

程序按左、上、右、下读取实测边框，并核对原始页与测量页的文字和图片位置。WPS 初次打开工作簿时若两次排版不同，会重新只读打开并核对。极小留白时会为跨出单元格边界的外框线保留完整线宽。

### V1.8.3 兼容与诊断更新（历史记录）

用户在 Windows 上报告 V1.8.2 返回 `0x8FE30C28`，旧日志不能区分原始 PDF 导出、工作表复制或测量导出。尚不能确定该次故障的具体 COM 调用和根因。

本版采用五个显式参数调用 `ExportAsFixedFormat`，省略不用的可选参数；使用单个 `Before` 参数复制临时工作表。每个关键步骤均记录开始、完成、原始错误码，清理错误不会覆盖此前的导出错误。优先使用常见中间纸型，不修改系统默认打印机。

这是兼容与诊断更新，尚未在用户的 Windows Excel/WPS 环境验证解决上述错误。失败时原有 PDF 保持不变。

## 从源码构建

需要 Windows 和 .NET Framework 4.7.2 Developer Pack。第三方依赖的固定版本、原始包地址和文件哈希记录在 `vendor/dependencies.lock.json`。

在仓库根目录打开 PowerShell 7（`pwsh`），执行以下命令。

```powershell
./scripts/build.ps1
./scripts/test.ps1
```

输出：`dist/unsigned/AutoPaperPDF.exe`。本机构建不包含代码签名。

GitHub 的 **Build and test** 工作流会在推送 `main`、Pull Request 和手动触发时执行构建、测试，并保存未签名的 EXE 构建产物。

测试覆盖命名、设置持久化、纸型候选、页边距、实际打印边界、内容宽高大于预估、位置偏移、旋转页、Form XObject、内容指令保留和异常保护；不自动启动 Excel/WPS，也不替代 Windows 图形界面和真实表格导出的人工验证。
